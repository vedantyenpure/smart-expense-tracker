# 💰 Smart Expense Tracker

A web-based expense tracking application built using Python, Streamlit, and MySQL to manage income, expenses, budgets, and financial insights through an interactive dashboard.

## 🌐 Live Demo

[**Open Smart Expense Tracker**](https://smart-expense-tracker-zcufgwaqgu7yemnvdv3bu2.streamlit.app/)

## ✨ Features

- ➕ Add and manage income
- 💸 Track daily expenses
- 📊 Interactive dashboard and charts
- 🗂️ Categorize expenses
- 🎯 Set and monitor monthly budgets
- 📅 Filter transactions by date
- 📥 Export expense data to CSV
- 🗄️ MySQL database integration

## 🛠️ Tech Stack

- **Language:** Python
- **Frontend:** Streamlit
- **Database:** MySQL
- **Data Analysis:** Pandas
- **Charts:** Streamlit visualizations
- **Deployment:** Streamlit Community Cloud
- **Version Control:** Git and GitHub

## 🚀 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/vedantyenpure/smart-expense-tracker.git
   ```

2. Open the project folder:

   ```bash
   cd smart-expense-tracker
   ```

3. Create and activate a virtual environment:

   ```bash
   python -m venv .venv
   ```

   Windows PowerShell:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

4. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Configure your MySQL database credentials using environment variables or Streamlit secrets. Never commit passwords or secret credentials to GitHub.

6. Start the application:

   ```bash
   streamlit run app.py
   ```
